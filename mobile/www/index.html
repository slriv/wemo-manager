WeMo Manager

Server settings

Hostname or IP address of the machine running WeMo Manager — port 8000 is assumed. A hostname is replaced with its IP address once connected, so setup keeps working when this phone has no DNS.

Plug in the new WeMo device (or hold its button ~5s for a Wi-Fi reset on an existing one) and wait for its light to blink.

Open your phone's Wi-Fi settings and join the device's own network — it looks like Wemo.Mini.123 or WeMo.Switch.ABC and has no password.

If Android warns that the network has no internet access, choose "Stay connected" — otherwise it will silently switch back and the next step will fail.

Now switch your phone's Wi-Fi back to your home network. The device is joining it too; this can take a minute.
